# Car Maps 🚗

iPhone app: Google Maps + turn-by-turn voice navigation.
It sends its own map and the directions to the Tesla browser over the iPhone hotspot Wi-Fi
(local only, no internet needed in the car).

## Get the IPA
GitHub → Actions → "Build IPA" → latest run → download **CarMaps-ipa**.
Install it on your iPhone with **Sideloadly** (free, Mac) using your Apple ID.

## Use
1. Open the app, paste your Google Maps API key (once).
2. iPhone: Personal Hotspot ON. Tesla: connect to the iPhone Wi-Fi.
3. Tesla browser: `http://172.20.10.1:8080`
4. Search a place, tap it, drive.
